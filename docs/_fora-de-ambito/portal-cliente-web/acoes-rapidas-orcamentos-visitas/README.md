## Descrição

Criar as interfaces HTML/CSS para o cliente interagir com a Guimágua (agendar manutenção, pedir orçamento com foto e ver histórico).

- Grelha de botões de Ações Rápidas (Agendar Manutenção, Orçamento com Foto, Histórico Leituras, Chat Guimágua).
- Cartão informativo da "Próxima Visita Agendada" com foto/nome do técnico atribuído e data/hora.
- Formulário modal em HTML/CSS para submissão de pedido de orçamento/avaria com zona de upload de fotografias.
